# Satelle

Satelle is a self-hosted control plane for durable native Computer Use.

Install the `satelle` executable from crates.io:

```sh
cargo install satelle
```

This package exposes the command-line executable as its supported installation
surface. Its Rust modules are internal and do not have a stable API guarantee.

See the [repository](https://github.com/Microck/satelle) for setup, security,
platform support, and release documentation.

## Core principles across all workflows

1. **The Host owns execution:** The Host Daemon manages the session lifecycle,
   desktop interactions, and provider secrets. A network disconnect does not
   abort an active session or corrupt state.
2. **Durable session handles:** Every session produces a stable `session_id`.
   Use this handle across commands and processes to inspect, steer, or stop work.
3. **Structured outputs for automation:** Use `--json` for predictable automation,
   and `--events human` or `--events json` for live streaming observation.
4. **Zero credential leakage:** Provider secrets remain resolved on the Host.
   Logs and diagnostic outputs redact sensitive tokens by default.
